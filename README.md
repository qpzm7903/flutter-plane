# 苍穹战机

经典竖版飞机大战：拖动战机躲避弹幕、自动开火、击破编队与 Boss，在连击倍率中冲刺最高分。
覆盖 **Android / Windows / Web**，完全本地运行，无需联网。

## 特色

- **完整战斗循环**：六级弹道（脉冲→双联→裂波→穿甲→新星，4 级起主炮可穿透）、僚机护航、护盾、全屏炸弹、急速射击、连击倍率（最高 ×4）与波次递增难度。
- **七类敌机 + 三形态 Boss**：侦察机、战斗机、轰炸机、精英机、截击机、自爆无人机与重装堡垒
  各有移动与开火方式；每 4 波迎战 Boss，赤蝎母舰、深渊利维坦与幽影方舟依次登场，
  各四段弹幕并带独立血条。
- **僚机编队**：左翼疾风速射、右翼重炮重击，最多两架，跟随走位并向外侧补射。
- **每日挑战**：每天固定随机种子与一种战场修正（弹幕压制 / 重装舰队 / 补给管制 /
  单机突入 / 火力演习），独立记录今日最佳、出战次数与连续参与天数。
- **成就系统**：13 项成就覆盖首战、分数、波次、累计击破、连击、Boss 与每日挑战，
  累计战绩跨局保存，结算时即时提示新解锁。
- **纯粹的程序化视听**：星空、战机、弹幕、爆炸全部用 Canvas 矢量绘制；九种音效与 8 秒电子循环
  背景音乐在运行时合成，仓库不存放图片、字体与音频文件。
- **自适应战场**：竖屏手机、折叠屏、平板与桌面窗口自动选择战场比例；战场上下始终铺满
  屏幕边缘，满屏时不加外框，HUD 悬浮在战场四周，提示变化不会挤压战场。
- **批绘制与对象池**：星空、粒子、敌弹与爆炸碎片按颜色分桶，玩家弹按弹种分桶合并绘制，粒子对象回收复用；
  弹幕每帧只遍历两趟，240 颗弹幕的三层外观只需 12 次以内的绘制调用，满级弹道加双僚机的玩家弹约 18 次以内绘制调用；
  再加 150 颗单类敌弹的测试预算为 20 次，三类混合敌弹预算为 24 次。
- **轻量每帧开销**：战场背景按尺寸录制为一张画面，每帧只提交一次；文字排版与淡出颜色
  分档缓存，尾焰路径预建，屏幕外特效直接裁剪；结算面板出现后暂停引擎，静止战场不再重绘；
  HUD 只在可见数值变化时重建，Boss 血条走独立通知；音效与音乐合成放在后台 isolate。
- **可调逻辑刷新率**：30Hz 省电 / 60Hz 均衡 / 120Hz 顺滑（默认 60Hz），固定步长推进，
  低帧率下也不会出现子弹穿透。
- **本地记录**：最高分、最远波次与出击次数自动保存；日志按天写入用户目录，方便排查问题。
- **单一出处**：拾取规则、HUD 条目、扫掠判定、战场边界与战机轮廓各自只有一份实现；
  二级页面外壳、内容卡片、统计条、偏好读写与日期解析也各自收敛到一处，
  玩法说明由调参表生成，调整数值不会让界面文案过期。

## 操作

| 平台 | 移动 | 炸弹 | 暂停 |
| --- | --- | --- | --- |
| 手机 / 平板 | 拖动屏幕 | 点击右下角炸弹按钮 | 右上角暂停按钮 |
| Windows / Web | 拖动鼠标，或方向键 / WASD | 空格 / B，或点击炸弹按钮 | Esc / P，或点击暂停按钮 |

自动开火，无需点击射击。

## 玩法

1. 击破敌机累积连击，12 / 30 / 60 连击分别提升分数倍率，停火 2.6 秒后连击归零。
2. 拾取补给：**火力**（提升弹道等级，4 级起主炮穿透一架普通敌机）、**护盾**（抵挡一次伤害）、**炸弹**（补充全屏炸弹，上限 3 枚；精英机/堡垒每 4 次击破必出，告急时另有保底）、
   **分数**（直接加分）、**急速**（限时提升射速）、**僚机**（左翼疾风速射、右翼重炮重击，最多 2 架）。
3. 每 4 波出现 Boss，赤蝎母舰、深渊利维坦与幽影方舟依次登场；击破后掉落三份补给（含必出炸弹，炸弹满额时改为护盾）。
4. 每日挑战按日期生成固定种子，五种战场修正逐日轮换；挑战独立计分，首页卡片可直接开战。
5. 生命耗尽即战斗结束，最高分与本局波次自动保存；累计击破与成就在普通战斗和挑战中共同推进。

## 技术栈

- Flutter 3.47.9 + Flame 1.38.2
- 状态：Provider；本地存储：shared_preferences
- 音频：flutter_soloud（播放运行时合成的 WAV）
- 桌面窗口：window_manager；Web 中文字体：soup_fonts

## 开发

```shell
flutter pub get
flutter analyze
flutter test

# 运行（Windows / Web）
flutter run -d windows
flutter run -d chrome
```

当前包含 282 项单元与组件测试，覆盖战斗流程、弹道、碰撞、特效、批绘制、视口裁剪、僚机、
三形态 Boss、波次、HUD 刷新、拾取规则、每日挑战、成就判定、页面外壳与三端界面。

Android 配置：`minSdk=35`、`targetSdk=37`、`compileSdk=37`，仅构建 `arm64-v8a`。
Windows 与 Web 平台文件由 CI 在构建时生成，仓库不存放 `windows/`、`web/` 目录。

### 目录结构

```
lib/
  app.dart / main.dart          应用入口与主题、生命周期
  flame/                        Flame 游戏、战场渲染、批绘制与敌机视觉表
  game/battle/                  战斗逻辑：实体、波次、弹道、移动、碰撞、特效
  game/challenge/               每日挑战：日期种子、战场修正与进度快照
  game/achievements/            成就目录、累计战绩快照与解锁判定
  game/logic_rate.dart          30/60/120Hz 逻辑速率与固定步长
  pages/                        首页、战斗页、成就页、设置页与悬浮 HUD
  providers/                    用户偏好与战斗结算
  services/                     日志、存储、音效与音乐合成（后台 isolate）
  theme/ utils/                 主题、常量、格式化、窗口与全屏
test/                           单元测试与组件测试
.github / .gitea                GitHub / Gitea 构建发布流水线
```

### 日志位置

- Windows：`%USERPROFILE%\Documents\FlutterSkyFighter\logs\app_yyyyMMdd.log`
- Android：应用外部存储目录下的 `FlutterSkyFighter/logs/`
- Web：仅保留内存日志，可在设置页查看

日志按天滚动，保留 7 天，单个文件超过 5MB 自动轮转。

## 构建与发布

构建全部在 CI 完成。推送 Tag 不会自动出包，需要在 Actions 中手动运行 `build.yml` 并选定该 Tag：

```shell
git tag -a v0.5.0 -m "v0.5.0: 弹道、僚机、波次与炸弹掉落深化"
git push origin v0.5.0
tea actions workflows dispatch build.yml --ref refs/tags/v0.5.0 --follow
```

产物包含 Android APK（aarch64）、Windows ZIP（x86_64）与 Web 压缩包，并发布到 Releases 与 Pages。
